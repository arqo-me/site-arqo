## Техническое Задание (ТЗ): SEO-масштабирование ARQO (Уровни 1, 2, 3)

**Цель:** Создать архитектуру БД в Strapi, которая позволит автоматически генерировать тысячи посадочных страниц за счет перемножения параметров: `Услуга` × `Комната/Тип жилья/Стиль` × `Локация (ЖК/Город)`.

### 1. Изменения в Strapi (Бэкенд)
Вместо того чтобы плодить разные сущности, мы создадим единую коллекцию **"Теги услуг" (Service Tags)** или **"Категории"**.

**Новая коллекция: `Service Category`**
- `Name` (String): Название (например, "Ванная комната", "Новостройка", "Минимализм")
- `Slug` (UID): (например, `bathroom`, `novostroyka`, `minimalism`)
- `Type` (Enumeration): `room` (Комната), `property_type` (Тип жилья), `style` (Стиль)
- `Description` (Rich Text): Общее описание SEO-текста для этой категории.
- `Services` (Relation): Many-to-Many с коллекцией `Service` (К каким локальным услугам относится этот тег. Например, "Новостройка" относится к "Ремонту", а "Минимализм" — к "Дизайну").

**Изменения в `City` (Локации):**
- Связать с `Service Category` (Many-to-Many), если нужно (опционально).

### 2. Логика генерации URL (Next.js Фронтенд)
Фронтенд будет динамически собирать адреса по формуле: `/services/[service-slug]/[category-slug]/[city-slug]`

**Примеры генерации роутов для `generateStaticParams`:**

1. **Только Услуга + Категория (Уровни 1 и 2):**
   - `/services/apartment-renovation/bathroom`
   - `/services/apartment-renovation/novostroyka`
   - `/services/interior-design/minimalism`

2. **Перемножение: Услуга + Категория + Локация (Уровень 3):**
   - `/services/apartment-renovation/novostroyka/eko-bunino`
   - `/services/interior-design/kitchen/skandinaviya`
   - `/services/premium-fit-out/vtorichka/khamovniki`

### 3. SEO-компоненты на фронтенде
- **Динамический H1:** Должен собираться из названий: *"{Услуга} {Категория} в {Локация}"* -> *"Ремонт квартир в новостройке в ЖК Эко Бунино"*.
- **Динамические Мета-теги:** Next.js `generateMetadata` должен формировать Title и Description по шаблону.
- **Sitemap.xml:** Обязательная генерация XML карты сайта со всеми возможными комбинациями из БД, чтобы поисковые системы узнали о тысячах новых страниц.
- **Хлебные крошки (Breadcrumbs):** *Главная -> Услуги -> Ремонт квартир -> Новостройки -> ЖК Эко Бунино*.

### 4. Этапы реализации
1. **Шаг 1:** Обновление моделей в Strapi (Создание `Service Category` и связей).
2. **Шаг 2:** Написание скрипта Seed для автоматического заполнения 30+ популярных комнат, стилей и типов жилья.
3. **Шаг 3:** Разработка динамических роутов в Next.js: `src/app/services/[slug]/[categorySlug]/page.tsx` и `src/app/services/[slug]/[categorySlug]/[citySlug]/page.tsx`.
4. **Шаг 4:** Внедрение универсального SEO-компонента (Metadata + Breadcrumbs) и генератора `sitemap.xml`.
